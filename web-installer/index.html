Connect an ESP32-S3.

Web Serial is unavailable. Open this page in desktop Chrome or Edge. Web Serial requires HTTPS or localhost.

Research firmware: the current build validates the core and TapDrop foundation; stock-iPhone transfer is not claimed yet.
